# Dashboard

Use a saida de `python scripts/calcula_kpis.py relatorios/AAAA-MM/conformidade.csv` como fonte para quatro paineis:

1. releases totais;
2. percentual de releases assinadas;
3. percentual de releases com provenance;
4. percentual de releases conformes.

O arquivo de exemplo permite montar e capturar o dashboard antes de integrar uma fonte real.
